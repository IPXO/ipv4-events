# ipv4.events

Welcome to **ipv4.events**, a community-driven timeline of the Internet's IPv4 era — from ARPANET and TCP/IP to cloud, AI, space, and beyond.
The site uses a nostalgic **Windows 95-style design** and runs on GitHub Pages.

## Live Website
[https://ipv4.events](https://ipv4.events)

## Event Format

Each event is a JSON object in one of the files under `docs/data/events/`.

```json
{
  "id": "1981_rfc791",
  "year": 1981,
  "categories": ["Standards"],
  "title": "RFC 791 — IPv4 Published",
  "overview": "The Internet Protocol version 4 (IPv4) is standardized in RFC 791, defining the dominant packet format for decades.",
  "hashtags": ["RFC791", "IPv4", "Standards"],
  "links": {
    "wikipedia": "https://en.wikipedia.org/wiki/IPv4"
  }
}
```

### Fields

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Unique identifier — lowercase, underscores, no spaces |
| `year` | integer | yes | e.g. `1981` |
| `categories` | string[] | yes | One or more IDs from `categories.json` |
| `title` | string | yes | Short event title |
| `overview` | string | yes | 2–3 sentence description |
| `hashtags` | string[] | yes | Keywords for search and filtering |
| `links.wikipedia` | string | no | URL to the relevant Wikipedia article |

## Categories

Categories are defined in `docs/data/categories.json` and are organized into **10 groups**:

| Group | Categories |
|---|---|
| Standards & Governance | Standards, Governance, RIRs |
| Networking & Backbone | Networking, Backbone Speeds, Submarine Cables, Wireless, IXPs & NOGs, Hardware & Vendors |
| Operating Systems | Windows OS, Linux Distros, Mobile OS |
| Programming & Software | Programming Languages, Software & Tools, Web Browsers, Streaming & Multimedia |
| Social & Messaging | Social Networks, Messaging |
| AI & Emerging Tech | Artificial Intelligence, Quantum & Next-Gen, Metaverse & XR |
| Security & Policy | Security, Policy & Regulation |
| Economy | Finance, Market |
| Cloud & Infrastructure | Cloud & Virtualization, Serverless, Edge Computing, CDN, Data Centers |
| Space & Satellite | Satellite Internet, Space |

The pill bar on the homepage groups categories by these labels, keeping the Win95 icon theme.

Each category entry in `categories.json` looks like:

```json
{
  "id": "Standards",
  "label": "Standards",
  "group": "Standards & Governance",
  "iconUrl": "icons/w98_help_book_small.ico"
}
```

## Contributing

We welcome contributions! The easiest way is to click **"+ Propose an Event"** on the homepage — it opens a pre-filled GitHub issue with the correct JSON snippet.

To contribute directly, please read [CONTRIBUTING.md](CONTRIBUTING.md).

### After adding or changing categories

If you add a new category to `categories.json`, regenerate the pretty-URL stubs and update the sitemap:

```bash
node scripts/generate-pretty-pages.mjs
# then manually add the new URL to docs/sitemap.xml
```

## Development

The site is pure static HTML + vanilla JS hosted on GitHub Pages — no build step required.

- **Icons**: Windows 95/98 Icon Set
- **Design**: Windows 95/98 nostalgia with modern responsive layout
- **Deployment**: GitHub Pages auto-deploys from `/docs/` on push to `main`

### Running locally

```bash
npx serve docs
# open http://localhost:3000
```

### Key files

| File | What it does |
|---|---|
| `docs/js/app.js` | Parallel data fetch, hash routing, grouped pill rendering, contribute modal |
| `docs/css/style.css` | All styles — retro theme, grouped catbar, modal, decade jump nav |
| `docs/data/categories.json` | Canonical category list — edit this to add/rename categories |
| `docs/data/events/manifest.json` | Load order for event JSON files |
| `scripts/generate-pretty-pages.mjs` | Run after adding categories to regenerate stub pages |

## SEO

- All category and decade pages have canonical `<link>` tags pointing to their trailing-slash URLs
- `docs/sitemap.xml` lists all URLs with trailing slashes (matching what GitHub Pages serves)
- `docs/robots.txt` references the HTTPS sitemap only
- Meta descriptions are under 155 characters
